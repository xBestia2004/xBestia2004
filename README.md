## O mnie

Jestem technikiem informatykiem i studentem informatyki na Katolickim Uniwersytecie Lubelskim. Łączę praktyczną pracę ze sprzętem z administracją systemów **Linux** i **Windows**, wirtualizacją oraz automatyzacją powtarzalnych zadań.

Prowadzę **[Wilczy Sprzęt](https://wilczysprzet.pl/)** — serwis i laboratorium sprzętowe w Lublinie: diagnostyka i naprawa, laptopy poleasingowe, wdrożenia Linuksa i Proxmoxa, sieci oraz kopie zapasowe. Pracuję stacjonarnie i zdalnie.

- 📍 **Lokalizacja:** Lublin, Polska
- 🎓 **Edukacja:** technik informatyk · informatyka (KUL)
- 🧪 **Zainteresowania:** Linux, Proxmox VE, DevOps, sieci, bezpieczeństwo systemów, homelab

Wybrane certyfikaty Cisco Networking Academy (Linux, sieci, cybersecurity, Python) znajdziesz na [stronie portfolio](https://dariuszkisiel.pl/).
